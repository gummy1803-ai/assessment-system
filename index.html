  2. 在项目中打开 SQL Editor，粘贴并执行本项目 supabase-schema.sql 的全部内容
  3. 打开 Settings → API，复制 Project URL 和 anon public 密钥
  4. 编辑本项目的 config.js，填入这两个值并保存
  5. 刷新本页面即可使用
